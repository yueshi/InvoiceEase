在 WorkBuddy 中访问发票易 Web 页面 · 操作步骤

一次性免登深链（web_url）机制 · 2026-10-05 · 关联设计：design/2026-10-03-Agent跳转Web后台-深链与免登票据设计.md

一、机制一句话

Agent 调用发票易 MCP 工具时，工具出参会附带一个已筛选好的页面链接（web_url，内含一次性免登票据）， 在 WorkBuddy 回复里点开即直达 Web 后台对应页面，未登录浏览器也免登录。

{web_base_url}/invoices?status=pending_review&ticket=<一次性票据>

票据：一次性（用过即废）、默认 480 分钟有效、绑定签发时的用户身份；兑换后签发的是该用户的普通会话，不放大任何权限。

二、一次性配置（4 步）

1后端与 Web 启动 + 配置后台地址

cd backend && uv run uvicorn invoicing.main:app --reload   # 后端 :8000
cd web && npm run dev                                      # Web :5173

在 backend/.env 配置 Web 后台对外地址（空 = 不产出链接）：

INVOICING_WEB_BASE_URL=http://localhost:5173
使用场景填写值
只在本机浏览器点开http://localhost:5173
手机 / 微信 / 别的电脑点开（企业内网）http://<本机局域网IP>:5173，且 Web 以 npm run dev -- --host 启动
生产部署后台对外域名，如 https://invoice.example.com
修改 .env 后必须重启后端（配置只在进程启动时加载一次）。可选：INVOICING_WEB_TICKET_TTL_MINUTES=480 调整票据有效期，0=关闭免登（链接仍产出，但落登录页）。

2签发个人令牌（Web 后台）

  1. 登录 Web 后台 → 侧栏底部「令牌管理」→ 签发新令牌
  2. 名称如「WorkBuddy-张三」；权限点按角色一键填充；有效期建议 90 天
  3. 当场复制明文令牌——只显示一次，关掉后不可再查看
开发环境可临时用 .env 里的 INVOICING_MCP_TOKEN（内建管理员令牌）快速验证； 生产已默认关闭该通道，必须用个人令牌——Agent 以令牌归属人的身份与数据范围执行（员工只看得到自己的票）。

3WorkBuddy 注册发票易 MCP

编辑 ~/.workbuddy/mcp.json，与既有 mcpServers 合并：

{
  "mcpServers": {
    "invoice-ease": {
      "type": "streamable-http",
      "url": "http://127.0.0.1:8000/mcp",
      "headers": { "Authorization": "Bearer <第 2 步复制的令牌明文>" }
    }
  }
}
  • WorkBuddy 不在本机时，url 换成 http://<服务器IP>:8000/mcp
  • 配置格式以 WorkBuddy 平台实际支持的字段为准（以其 UI/文档校正）

4导入 Skill 话术（让 Agent 主动附链接）

mkdir -p ~/.workbuddy/skills/invoice-auto-collect
cp docs/workbuddy-skill/SKILL.md ~/.workbuddy/skills/invoice-auto-collect/

SKILL.md 内含「页面跳转（web_url）」条款：Agent 必须在汇总结论后附「🔗 去后台处理」链接， 且不得改写/截断链接参数。不导入则 Agent 可能拿到 web_url 也不展示。

三、日常使用（每次访问页面）

  1. 在 WorkBuddy 对话里正常提问，例如：
    「看看待复核的发票」「本月成本多少，出个图」「我有哪些报销单在审批中」
  2. Agent 调 MCP 工具取数，回复结论后附一行链接：🔗 去后台处理
  3. 点击链接 → 浏览器直达已筛选好的页面：
    • 未登录 → 自动兑换票据进入（免登）
    • 已有登录会话 → 不兑换，剥掉票据直接进目标页
    • 票据过期/已用过 → 落登录页并提示「登录链接已失效，请重新登录」

地址栏里的 ticket 会被自动剥离，不残留、不随页面转发。

哪些工具会带页面链接

工具点开后落到
invoice_list发票列表（回填本次筛选条件，如状态/关键词）
invoice_detail发票列表并自动打开该张详情抽屉
expense_list报销管理，逐条附对应报销单深链
receipt_list暂未附回单深链为 P1 遗留项
深链口径：带业务参数的链接默认按全部时间查询（Agent 场景常跨月），避免点开是空的。

四、自检与排查

快速自检（后端本机执行）

cd backend
uv run python -c "
from invoicing.web_links import web_link
print(web_link('/invoices', user_id=1, status='pending_review'))"

打印出带 ticket= 的完整链接 = 配置生效；输出 None = INVOICING_WEB_BASE_URL 未配置或后端未重启。

排查表

现象原因与处置
Agent 回复里没有链接① web_base_url 为空 → 配置并重启；② Skill 未导入 → 做配置第 4 步；③ 该工具本就不附链接（见上表）
点击后要求登录票据超过 480 分钟、或已被点击过（一次性）→ 重新问一次 Agent 获取新链接，或在登录页正常登录
提示「登录链接已失效」同上，属预期降级；登录页保留 redirect，登录后仍回目标页
本机能点、手机/微信点不开web_base_url 是 localhost，只解析于本机 → 换局域网 IP 或域名，Web 加 --host 启动
Agent 报 401 / 工具被拒令牌过期/被撤销/归属人被暂停；或令牌 scope 不含该工具所需权限 → 到「令牌管理」核对重签
点开是登录页且无 expired 提示正常冷启动（无票据直达）→ 登录即可

五、安全边界（必读）

  • 链接 = 一次性会话入口：点开即以其归属人身份进入。请勿转发到群/朋友圈；转发等于把登录入口给人。
  • 未被点击前，票据在有效期内可被他人使用——企业内网 + 全量审计（LOGIN / web_link 渠道）兜底；需要更严就把 TTL 调小。
  • 进入后台后一切照旧走 RBAC：数据范围、操作权限与该用户账号完全一致，票据不会多给一分权限。
  • 票据原文不落审计日志；链接本身请当作敏感信息对待。
