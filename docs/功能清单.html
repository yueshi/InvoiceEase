发票易（InvoiceEase）· 功能清单

电子发票自动化处理 AI Agent · 当前版本快照 2026-09-13 · 依据代码实测整理，非规划稿

一、产品定位

面向企业级市场的电子发票自动化处理 AI Agent，覆盖 「邮箱收取 → 智能解析 → 验真查重 → 报销入账 → 归档提交」全流程， 并通过 MCP 协议把全部能力开放给 WorkBuddy 等 Agent 平台调用。

合规基线：财会〔2025〕9 号文 —— 只收原件（拍照/截图拒收）、必存含数字签名的 XML 原件、 验真覆盖率 100%、审计可追溯、支持纯离线部署。

十一、状态机与关键约束

发票状态机

收取中 → 已收取 → 解析中 → 解析完成 → 验真查重中 → 待提交 / 待复核 / 已拦截 → 已提交 → 已归档

报销状态机

草稿 → 待审批 → 已通过 / 已驳回 → （撤回回到草稿）

写进数据库的硬约束

约束实现方式
发票号码全局唯一唯一索引（进销项共用一张表，一张票不会既是进项又是销项）
一票一报明细表的部分唯一索引（仅对 active 且挂了发票的行生效）+ 应用层前置校验
一信多票不重复收Message-ID 复合唯一索引
同文件不重复解析文件 SHA256 唯一
删除必释放删除 / 驳回 / 撤回均释放发票占用，否则发票永久卡在「已报销」
