发票易 · Web Agent 助手使用说明

右下角「AI」悬浮球 · 自然语言查发票 / 建报销 / 对回单 / 出报表 · 2026-10-01

一、入口

  • 登录后任意页面右下角都有蓝色圆形 AI 悬浮球，点击从右侧滑出「智能助手」抽屉，不打断当前页面操作。
  • 抽屉顶部是会话栏：下拉切换历史会话、新建开启新对话、删除移除当前会话。每次打开抽屉会自动刷新会话列表（第一轮对话后自动生成的标题，下次打开时即可看到）。
  • 会话栏下方是上下文提示，自动带上传当前页面地址与打开的发票 / 报销单编号，助手据此理解「这张发票」「这单」指的是什么。
  • 输入区：Enter 发送 / Shift+Enter 换行；生成过程中按钮变「停止」可随时中止；出错后可点「重试」重发上一问。

二、能做什么（四类场景举例）

场景可以直接说
发票查询 「列出本月待复核的发票」「发票 12 现在是什么状态」「这个月有哪些异常发票？」「查看发票 12 的详情」
报销单 「帮我建一个差旅报销单」「哪些发票还能报销？」「把发票 3、5 加进报销单 #42」「报销单 #42 走到哪一步了？」
银行回单 「查一下 9 月回单清单」「这个月哪些费用还没有发票？」「把回单 8 和发票 12 配个对」
报表 「出 9 月成本报表」「本月整体健康报告」「按费用类型看一下这个月的构成」
助手每一步操作都会显示工具执行过程（如 invoice_list · 完成 · 12ms），它给出的每个数字都来自真实查询，可随时对照网页核对。

三、工具与权限（角色 → 能调什么）

所有登录用户都能使用助手，但能调用的工具被你的角色锁死（与 MCP 工具层的授权范围一致），并且只能看到你本人范围内的数据。

角色助手能做什么不能做什么
普通员工
employee		 查发票、导入发票、建报销单 / 加票 / 提交（需确认）、查回单清单 不能审批报销单、不能删除/放行发票、不能看报表与主数据
财务专员
finance_staff		 员工全部能力 + 审批报销单、回单维护与配对、销项发票、报表统计 不能删除/放行发票（invoice:admin 专属）、不能查看/修改主数据
财务主管
finance_manager		 与财务专员相同 同上
系统管理员
admin		 全部能力，含删除/放行发票、银行账户与公司信息维护 —
数据可见范围另由系统 RBAC 再次收窄：助手能看到的内容，不会超过你本人在网页上能看到的。

四、写操作确认规则

提交 / 删除 / 审批类工具属于写操作，助手在调用前会先用文字复述「将要执行的操作 + 关键参数」，等你回复「确认」之后才真正执行。该确认为助手提示词级约束（非界面强制弹框）。涉及：

expense_submit（提交报销单）、expense_approve（审批）、invoice_delete（删除发票）、invoice_unblock（放行拦截票）、invoice_update（修改发票字段）、red_invoice_link（补关联红字票）、bank_account_delete / company_info_delete（删除主数据）。

其余新增 / 导入 / 查询类（建草稿报销单、加票、导入、查询等）直接执行，无需确认。每轮对话都会写入审计日志（AGENT_CHAT），操作全程可追溯。

五、离线部署说明

  • 大模型端点由后端配置（INVOICING_LLM_BASE_URL 等环境变量），浏览器只访问自家后端接口，前端不直连任何外部地址。
  • 开启离线部署（INVOICING_OFFLINE_DEPLOY=true）时：若模型端点解析为公网地址，后端启动自检会直接拒绝启动（生产/strict 模式；开发模式仅告警）；配置为企业内网模型（如 vLLM）即可正常使用助手。
  • 未启用大模型（INVOICING_LLM_ENABLED=false）时助手仍可打开，只回复静态功能说明，不执行任何工具。

六、常见问题

Q1：提示「未启用大模型 / 只显示功能说明」，怎么开启？

这是静态兜底说明：助手当前只回答固定功能清单，不做真实查询。由管理员在后端启用 INVOICING_LLM_ENABLED=true 并配置 API Key（或内网模型端点）后重启服务即可。

Q2：会话会保留多久？

默认保留 90 天（agent_session_retention_days，按会话最后更新时间计算）。后台每日 03:47 自动清理超期会话，消息随之删除且不可恢复；重要对话结论建议及时记录到其他系统。

Q3：助手回答「权限不足」怎么办？

说明该操作超出你当前角色的授权范围（工具调用被权限校验拦下，返回「权限不足」）。请联系管理员确认角色配置，或改由有权限的同事执行。

Q4：生成到一半想停下 / 答错了想重来？

生成中点「停止」立即中止，已经生成的内容会保留；出错后点「重试」可用同一问题重新生成。
