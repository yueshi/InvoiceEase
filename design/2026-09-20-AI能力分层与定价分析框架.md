# AI 能力分层与定价分析框架（发票易当前阶段适配版）

> 日期：2026-09-20　性质：分析框架（决策用，非采购清单）
> 缘起：参考四层模型路由方案（前沿旗舰 / Flash 生成 / 结构化决策 / 确定性规则），
> 落地为发票易在「种子 PoC + 盒子方向」阶段的 AI 选型与定价逻辑工具
> 方法：四层结构 × 多元参与者（每层 ≥4 家，含开源与国际/国内） × 价格锚点（2026-09 快照，标注保质期）
> 关联：`design/2026-09-17-小模型离线发票提取调研.md`（层 3 的实证边界）、`design/2026-09-18-架构与成熟度评估.md`

## 〇、怎么用这个框架（三条使用纪律）

1. **按「每任务成本」而非每百万 token 单价做预算**——同一 agent 工作负载实测月成本在不同模型间差 29 倍（约 $370 vs $10,725），且输出/推理 token 占账单 60% 以上，单价表会系统性误导决策；
2. **每层至少看 4 个参与者再下结论**——本文每一层都列国际大厂 / 国内厂商 / 开源 / 垂直玩家四类，任一单点案例（包括我们自己的 PoC）不得直接外推；
3. **价格锚点保质期约半年**——下方数字为 2026-09 快照且含促销价与峰谷计价，采购前必须复核官方价页。

## 一、四层结构：价值边界、成本结构与定价逻辑

| | L1 前沿旗舰 | L2 高速生成（Flash） | L3 结构化决策 | L4 确定性规则 |
|---|---|---|---|---|
| **能力边界** | 复杂推理、开放生成、创意；能力上限壁垒 | 覆盖绝大多数通用文本生成 | 机器友好结构化输出、低延迟/低单价、置信校准 | 确定性问题、零幻觉、结果可复现 |
| **成本结构** | 算力重、延迟高、推理 token 按输出价计费 | 高吞吐摊薄，单价极低；缓存命中可再降 98% | API 侧逼近 L2；自托管为「电费+折旧」 | 边际成本≈0 |
| **定价逻辑** | 按能力上限定价，利润被算力成本压 | 定价权薄弱，纯性价比+工程稳定性竞争 | 阶段性靠架构差异与校准能力，非能力上限 | **无定价权**，但压低整条链的定价天花板 |
| **竞争格局** | 能力迭代军备竞赛；最强能力被移入受限通道不公开定价 | 高度内卷 + 价格战 | 三重压力：开源替代 / 云厂商复刻 / 小模型追赶 | 无人竞争，内化为工程资产 |
| **对发票易的角色** | 兜底件的兜底件（当前不接） | **主力执行层** | **自研资产层**（预判/初筛/盒子内推理） | **毛利护城河**（能规则化就规则化） |

### 1.1 价格锚点快照（2026-09，$/百万 tokens，输入/输出）

**L1 旗舰（各家主力档）**：
- GPT-5 1.25/10 · GPT-5.4 2.5/15 · GPT-5.5 5/30 · GPT-5.4/5.5 Pro 30/180
- Gemini 3 Pro / 3.1 Pro 2/12
- Claude Sonnet 5 2/10 · Opus 5 5/25 · Fable 5 10/50
- 结构性事实：批量价一律五折、缓存读取约输入价 10%、长上下文有翻倍档；**推理 token 不可见但按输出计费**

**L2 Flash**：
- Gemini 3.8 Flash 0.75/3.75（促销价，2027-01 起 1.5/7.5）· 3.5 Flash 1.5/9
- DeepSeek V4 Flash 峰 $0.44/1.32、谷 $0.22/0.66（2026-08 涨价并引入峰谷计价；缓存 $0.014）
- qwen3.7-flash 0.03/0.13（≤32K）· qwen3.8-flash 0.15/0.47 · qwen-flash ¥0.15/¥1.50
- 趋势信号：**L2 在打价格战**（行业 token 支出指数 2026-09-01 首次跌破 $1/百万），DeepSeek 是逆势涨价的特例——「最便宜的档位」每月都在变，选型别绑定单一供应商

**L3 结构化决策**：
- API 侧价格与 L2 重叠（小模型/flash 档同价区），差异化不在单价而在**结构化输出合规率**
- 自托管侧：RK3588 实测 15–18s/张（w8a8）、峰值内存 6.19GB、单日 500 张 ≈ 5 小时 —— **隔夜批处理可行、交互式不可接受**（本项目 09-17 调研）

**L4 规则**：无市场价格。它就是「0 元/张且 100% 准确」的基准线。

## 二、映射：发票易当前能力 → 层级归属

| 能力 | 当前实现 | 归属层 | 选型结论（当前阶段） |
|---|---|---|---|
| 数电票 XML / 内嵌 XBRL 直解 | `xml_parser` / XBRL 提取 | **L4** | 保持第一优先级——这是「能不过模型就不过模型」的实现 |
| 版式 PDF 文本层提取 | pypdf + 规则 | **L4** | 同上，不升级成模型 |
| 关键字段校验（税号校验位、价税合计勾稽、大小写） | `validation.py` | **L4** | **比置信度阈值更可靠**，继续做所有模型输出的门控 |
| 合规判定（28 号公告、小额零星、一票一报） | `expenses.py` | **L4** | 绝不交给模型——这是定价故事里「确定性」的部分 |
| OCR（扫描件识别） | PaddleOCR（未部署） | **L3** | 盒子上线时机一并部署；喂版式/坐标而非 markdown |
| LLM 文本结构化 | DeepSeek 云端（已启用） | **L2** | 主力执行层；按每任务成本核算，不锁单一供应商 |
| 费用归类 | 规则优先 + LLM 兜底 | **L4→L2** | 规则命中率每提 1pp，L2 调用就少一笔——持续把 L2 的活往 L4 挪 |
| AI 复核预判 | `ai_review.py` 四层判定 | **L3** | 这正是「结构化决策」赛道：低单价、高并发、可校准；**改判埋点是这层唯一的护城河原料** |
| 模糊件兜底（VLM） | 通道未配 | **L1/L2 之间** | 当前不接：先靠「拒收 + 人工」兜，有真实客户量再评 |
| 盒子内推理 | 未建 | **L3 自托管** | 按 09-17 调研走「小模型初筛 + 确定性门控 + 人工兜底」，CPU-only 必须先实测 |

### 2.1 一张票的模型成本账（校准直觉用）

按「每张票 3k 输入 + 0.5k 输出 token」（走 LLM 的票）：

| 通道 | 月 500 张的成本 |
|---|---|
| qwen3.7-flash（0.03/0.13） | **约 $0.08** |
| DeepSeek V4 Flash 谷价（0.22/0.66） | 约 $0.50 |
| Gemini 3.8 Flash 促销价（0.75/3.75） | 约 $2.06 |
| 旗舰档（如 Opus 5，5/25） | 约 $13.75 |

**结论：在「单企业月几百张票」的量级下，L2 之间选谁的价格差是「几毛钱 vs 十几块钱」的差别**——模型成本相对于盒子/订阅定价（百元～千元/月量级）占比 <1%。因此：
- **不要按 token 定价，也不要把「省 token」当成架构目标**；
- 选型由**准确率、合规（离线）、工程稳定性**主导，价格只在同能力档内做筛选；
- 真正吃成本的是部署与运维（人肉陪跑），不是推理。

## 三、定价逻辑：四层的定价权与我们的位置

```
L1 能力上限定价（贵，被算力成本压）
        ▲ 约束
L2 商品化定价（弱定价权，价格战）      ← 我们买它的「执行」
        ▲ 约束
L3 阶段性定价（架构差异窗口，三重压力） ← 我们自研「决策」的地方
        ▲ 被压顶（记住这个方向）
L4 零定价（0元基准，压低上面三层天花板） ← 我们的毛利与确定性来源
```

三条推论：

1. **L4 越厚，产品越稳**：XML 直解与规则校验是 0 元且 100% 准确的路径，每一类「能规则化的票」都在保护毛利与合规；反之，如果 80% 的票要过模型，成本结构没变差多少（上面算过），但**确定性变差**——坏处不在钱在风险。
2. **L3 的窗口期是「现在」，但护城河必须换**：架构差异会被云厂商复刻、开源追平（09-17 调研里 2B 蒸馏已有绕过 schema 门槛的路径）。这层能守住的不是模型，是**垂直校准数据**——改判埋点（`ai_review`）积累的「什么票会判错、判错后人工怎么改」是云厂商拿不到的。
3. **对客定价锚在「替代了什么人力」，不在「用了什么模型」**：中小企业财务 3-5 分钟/张的人工成本是定价锚（PoC 复盘指标里的口径），模型层只是交付成本。对外叙事里**不要出现 token/模型分层**，客户买的是「票进去、合规出来」。

## 四、多元参与者矩阵（防单一案例外推）

| 层 | 国际 | 国内 | 开源/自托管 | 垂直玩家 | **外推风险** |
|---|---|---|---|---|---|
| L1 | OpenAI（GPT-5.x）、Google（Gemini 3 Pro）、Anthropic（Opus/Fable） | DeepSeek 高配档、月之暗面/MiniMax 旗舰 | Llama 系超大参数（私有部署） | — | 「旗舰能力」评测多为英文通用榜；对中文票的边际优势未验证；最强能力正被移入受限通道，公开价不代表可获取 |
| L2 | Gemini Flash、GPT-5 mini 档 | **DeepSeek V4 Flash（涨价+峰谷）**、Qwen flash 系、智谱 GLM、MiniMax | Qwen/GLM 开源小尺寸自托管 | 云厂商一体机 | 价格战 + 峰谷计价 + 促销到期 ⇒ 任何「单价结论」半年即失效；缓存价口径各家不同（2%–25%）不可直接比 |
| L3 | Nanonets IDP、Google Document AI | 合合信息 TextIn、百度/腾讯 OCR、票据 SaaS | Qwen3-VL-2B、InternVL3.5、NuExtract 2.0（蒸馏） | 票据识别 SDK 厂商 | ① Nanonets 榜单自家第一（利益冲突）② 榜单语料为英文/合成 ③ RK3588 数据是单板单模型——**三层外推风险叠加，中文数电票必须自建评测集** |
| L4 | （无人定价） | ERP/银企/代账 SaaS 内嵌规则 | 全部自有 | — | 无外推风险；但要防「规则过时」——法规版本（28 号公告等）变更需回归 |

**自用纪律**：我们自己 PoC 的观察值 = 单一客户、单一批票型，汇报时按「案例」标注，不得升级为「市场结论」。

## 五、当前阶段（种子 PoC → 盒子）的行动与重估触发

### 5.1 现在做什么

| 动作 | 理由 |
|---|---|
| L2 保持「可替换」：LLM 走 OpenAI 兼容层（已实现），不写死供应商 | 价格战环境下半年一换是常态，¥0.80～$3.75/百万的档位差异随时翻转 |
| L4 持续加厚：归类规则命中率、校验规则覆盖 | 零成本 + 零风险 + 压住高层定价，三重收益 |
| L3 只做「校准」不做「模型」：改判埋点数据积累与阈值调优 | 护城河在数据；模型能力等 09-17 调研的空白实验补完再说 |
| 盒子内 L3：先跑通「小模型初筛 + 规则门控 + 人工兜底」，CPU-only 实测优先 | 09-17 调研明确：CPU-only 是证据空白，不可默认可行 |
| L1 当前不接 | 月 500 张量级用不到；真遇到极难件，拒收 + 人工比调旗舰便宜两个数量级 |

### 5.2 何时重估（触发条件）

1. **L2 价格再降 5 倍**（如 flash 档跌到 $0.01/百万级）→ 重新评估「盒子内自托管」的 TCO 优势是否还存在（可能云端直连更划算）；
2. **开源小模型在中文数电票上的实测精度达标**（自建评测集上关键字段 ≥ 人工复核门槛）→ L3 自托管窗口打开，盒子方案成立；
3. **云厂商复刻结构化决策**（把「票据→结构化+置信度」做成标准 API 且带合规资质）→ 我方 L3 自研价值重估，护城河退回改判数据与流程；
4. **旗舰能力全面受限通道化**（公开价买不到最强能力）→ 「能力上限」叙事的商业含义变化，对盒子（本地算力）反而是利好；
5. **法规版本变更**（发票/税前扣除规则）→ L4 全面回归，这与模型无关但优先级最高。
