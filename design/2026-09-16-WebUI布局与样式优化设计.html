发票易 · WebUI 布局与样式优化设计

V1.0 · 2026-09-16 状态：设计已确认，待实施 视觉方向：B 亮侧栏轻盈现代 主色：科技蓝 #2563EB 路线：antd token + 全局 CSS · 零新依赖

1. 现状诊断（设计依据）

  • 布局：暗色侧栏零定制、顶栏仅用户名+两按钮、内容区无 max-width（宽屏表格拉伸折行）、页面标题为裸 <h3>、筛选工具栏每页各自为政、工作台卡片写死 span=6
  • 样式：全项目仅 antd reset.css，无设计 token / 全局 CSS；未用 ConfigProvider 主题；约 100 处行内 style 散布 15 个文件，仅 3 个文件有 <style> 块；金额无千分位、列宽未约束
决策过程存档：.superpowers/brainstorm/15452-1789569174/（三方向布局 mockup + 三主色对比，浏览器点选定稿）

2. 设计 Token 层（一处定义，全局生效）

ConfigProvider（App.vue 根部包裹）

Token值说明
colorPrimary#2563EB品牌主色，全组件联动（按钮/链接/焦点/选中态）
borderRadius8按钮/输入框/卡片圆角
colorBgLayout#F6F7F9内容区底色
menu tokenitemSelectedBg #EFF6FF 等亮色菜单替代 theme="dark"，选中项蓝字浅蓝底圆角 6

全局样式 src/styles/global.css（新增）

  • CSS 变量：语义色 --c-warn #D97706 / --c-danger #DC2626 / --c-success #059669；间距刻度 --space-1..6；卡片阴影 --shadow-card
  • 页面模式类：.page（max-width 1280px 居中，根治宽屏拉伸）、.page-header（标题 20px + 描述 + 动作区）、.filter-toolbar / .table-card（白卡容器）、.num（金额列 tabular-nums）
  • 归位规则：静态视觉进 scoped style 或全局类，行内 style 仅允许动态值（本轮为执行约定，不改 ui-conventions.spec）

3. 布局骨架（App.vue 重构）

┌────────────┬──────────────────────────────────────────┐
│ 品牌区      │ 顶栏 56px：页面标题(meta.title)   用户名 ▾ │
│ logo+发票易 ├──────────────────────────────────────────┤
│ 亮色菜单    │  .page 容器（max-width 1280）             │
│ (角色收敛)  │    PageHeader(title/desc/extra)          │
│            │    filter-toolbar → table-card → ...      │
└────────────┴──────────────────────────────────────────┘
  • 侧栏：白底 + 细分隔线，宽 208；品牌区 = 蓝色渐变圆角方块内白色「发」字 +「发票易」
  • 顶栏：左侧当前页面标题（router meta.title 新增）；右侧 a-dropdown（首字头像 + 修改密码/退出登录），两颗常驻按钮移除
  • 菜单角色收敛逻辑保持现有 computed 不变；不做侧栏折叠（YAGNI）
  • 新组件仅 PageHeader.vue：props title/desc + slot extra，10 页统一套用

5. 测试与验收策略

  • 每页改完跑全量 npm run test（66s）；断言随新 DOM 同步修，不删用例
  • 新增 spec：PageHeader 组件（title/desc/extra 渲染）
  • npm run build（vue-tsc 类型检查）必须通过
  • 手工验收：5173 全页面 + 抽屉/弹窗，与 mockup 对照
  • 硬约束 浅色主题不变；不改任何 API 层与业务逻辑（纯表现层）
