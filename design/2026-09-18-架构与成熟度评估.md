## 四、仍然原封的硬差距（今日逐条复核，均有 file:line）

### B1 验真仍是模拟
`verify/provider.py:19-22` 无真实国税 API 代码路径；披露机制健在（`verify_is_mock`、前端橙色 tag、月报声明）。注意新发现：`verify_is_mock` 判定靠 reason 前缀 `"mock_"` 字符串耦合（`schemas/invoice.py:70-73` ↔ `mock.py:21,26,28`），且该字段后端零消费方——mock 规则文案一改即静默失效。

### B2 安全基线六项全部未动
| # | 项 | 今日证据 |
|---|---|---|
| ① | jwt_secret 默认 `change-me` | `config.py:19`；自检仅 warn（strict 默认 false，`config.py:59`） |
| ② | 初始 admin `admin/admin123` | `config.py:37`、`bootstrap.py:8-18` |
| ③ | 无 CORS/TrustedHost 中间件 | `main.py` 全文件无 add_middleware，全库 grep 零命中 |
| ④ | 无登录限流/失败锁定 | `api/auth.py:41-69` 仅记审计 |
| ⑤ | `workbuddy_inbox_dir` 空 = MCP 可读任意路径 | `config.py:28` 默认空串，`mcp/extract.py:39-42` 仅非空时约束 |
| ⑥ | legacy MCP token 通道默认开启 | `config.py:22` 默认 `change-me` → 最小 id admin 全权（`verifier.py:51-81`） |

### B3 部署形态不存在（新增一条实证）
无 Dockerfile/应用 compose/nginx/backup.sh；且 **`backup.py:28,57-63` 仅支持 SQLite，非 sqlite 直接 RuntimeError——生产切 PG 当日，每日备份任务必然失败**，只能靠 backup.missing 告警兜底。

### B4 多租户仍空架子
6 处模型 default="default"、令牌签发硬编码（`workflow/mcp_tokens.py:105`）、无查询过滤。
