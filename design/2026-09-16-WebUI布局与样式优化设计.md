# 发票易 · WebUI 布局与样式优化设计

> 日期：2026-09-16　状态：已实施（2026-09-17，实施计划与偏差记录见 design/2026-09-17-WebUI布局与样式优化实施计划.md）
> 决策记录：目标=视觉档次 + 设计系统一致性 + 操作效率（全选）；视觉方向=**B 亮侧栏轻盈现代**（可视化 mockup 对比选出）；主色=**科技蓝 #2563EB**；技术路线=**antd ConfigProvider token + 全局 CSS，零新增依赖**。
> 可视化决策过程存档：`.superpowers/brainstorm/15452-1789569174/`（方向与配色 mockup）

## 1. 现状诊断（设计依据）

- 布局：暗色侧栏零定制、顶栏仅用户名+两按钮、内容区无 max-width（宽屏表格拉伸折行）、页面标题为裸 `<h3>`、筛选工具栏每页各自为政、工作台卡片写死 `span=6`
- 样式：全项目仅 antd reset.css，**无任何设计 token / 全局 CSS**；未使用 antd v4 ConfigProvider 主题；约 100 处行内 `style="..."` 散布 15 个文件，仅 3 个文件有 `<style>` 块；硬编码色值（#888 等）；金额无千分位、列宽未约束

## 2. 设计 Token 层（一处定义，全局生效）

### 2.1 ConfigProvider（App.vue 根部包裹）

| Token | 值 | 说明 |
|---|---|---|
| `colorPrimary` | `#2563EB` | 品牌主色（全组件联动：按钮/链接/焦点/选中态） |
| `borderRadius` | `8` | 按钮/输入框/卡片圆角 |
| `colorBgLayout` | `#F6F7F9` | 内容区底色 |
| menu token | `colorItemText #5B6472`、`colorItemTextSelected #2563EB`、`colorItemBgSelected #EFF6FF`、`radiusItem 6` | 亮色菜单替代 `theme="dark"`（antdv 4 命名；v5 的 `itemColor*` 在本版本静默失效） |

### 2.2 全局样式 `src/styles/global.css`（新增）

- **CSS 变量**：语义色 `--c-warn:#D97706`、`--c-danger:#DC2626`、`--c-success:#059669`；间距刻度 `--space-1..6`（4/8/12/16/24/32）；卡片阴影 `--shadow-card`
- **页面模式类**：
  - `.page` —— 内容容器，`max-width:1280px; margin:0 auto; padding:24px 24px 48px`
  - `.page-header` —— 标题 20px/600 + 描述 13px `--c-sub` + 右侧动作区（flex，gap 8）
  - `.filter-toolbar` —— 白卡容器（padding 12/16，flex wrap，gap 12），列表页筛选区统一
  - `.table-card` —— 表格白卡容器
  - `.num` —— `font-variant-numeric: tabular-nums`，金额/编号列
- **归位规则**（本轮为执行约定，不改 ui-conventions.spec）：静态视觉一律进 scoped style 或全局类；行内 style 仅允许动态值（列宽、条件高亮等）

## 3. 布局骨架（App.vue 重构）

```
┌────────────┬──────────────────────────────────────────┐
│ 品牌区      │ 顶栏 56px：页面标题(meta.title)   用户名 ▾ │
│ logo+发票易 ├──────────────────────────────────────────┤
│ 亮色菜单    │  .page 容器（max-width 1280）             │
│ (角色收敛)  │    PageHeader(title/desc/extra)          │
│            │    filter-toolbar → table-card → ...      │
└────────────┴──────────────────────────────────────────┘
```

- 侧栏：白底 + `1px #EEF0F3` 右分隔线，宽 208；品牌区 = 蓝色渐变圆角方块内白色"发"字 +「发票易」16px/700
- 顶栏：白底 + 底部分隔线；左侧当前页面标题（`router meta.title` 逐路由新增）；右侧 a-dropdown（用户名首字圆形头像 + ⌄）：菜单项 = 修改密码 / 退出登录——现有两颗常驻按钮移除
- 菜单逻辑保持现有 `computed` + 角色收敛不变
- 不做侧栏折叠（8 项菜单不需要，YAGNI）

### 新组件 `src/components/PageHeader.vue`（仅 1 个）

props：`title: string`、`desc?: string`；slot：`extra`（动作按钮区）。渲染为 `.page-header` 模式。10 页统一套用。

## 4. 逐页改造清单

| 页面/组件 | 改造内容 |
|---|---|
| App.vue | 骨架重构（§3） |
| LoginView | 品牌化：淡色背景 + 居中白卡 + logo + 产品名 + 一句话说明 |
| DashboardView | 统计卡 `a-col :xs=12 :md=6` 响应式；信任/抬头卡套模式；页头补描述 |
| InvoiceListView | 动作（上传/导入销项/导入清单/导出）收进页头 extra；筛选行规整；日期列定宽、金额千分位右对齐、表头防断字 |
| ReceiptsView | 工具栏拆分：筛选（周期+复选）留 toolbar，动作（上传/导出/刷新）进页头 extra；「待核对」高亮改类实现 |
| ExpensesView | 页头 + extra 动作；行内样式归位（页面最大 575 行，改造量最大） |
| McpTokensView | 页头 + 签发动作进 extra；scope/状态 tag 色统一语义变量 |
| SettingsView / AuditView / AsyncTasksView / ChangePasswordView | 页头 + 行内样式归位（SettingsView 四 tab 结构不动） |
| 4 个 Drawer/Modal 组件 | 宽度/间距/标签对齐 token 化，无结构改动 |

**效率与信息密度专项**：金额 formatter（`formatMoney`：千分位 + 保留 2 位，新增 `src/utils/format.ts`）；日期/金额列定宽不折行；表格 `size="middle"`；操作列统一 `type="link" size="small"`；空状态统一 `a-empty`；宽屏 1280px 容器。

## 5. 测试与验收策略

- **每页改完跑全量 `npm run test`**（66s）；断言随新 DOM 同步修，**不删用例**；`ui-conventions.spec` 静态约束保留
- 新增 spec：`PageHeader` 组件（title/desc/extra 渲染）
- `npm run build`（含 vue-tsc 类型检查）必须通过
- 手工验收：5173 全页面 + 抽屉/弹窗过一遍，与 mockup 对照
- 约束：浅色主题不变；不改任何 API 层与业务逻辑（纯表现层）
